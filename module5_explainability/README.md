# Module 5 – Explainability & Report Generation

## Overview
Module 5 provides **Explainable AI (XAI) visual explanations** and **automated clinical screening report generation** for the Diabetic Retinopathy (DR) Screening System.

It translates complex neural network attention features, lesion segmentation masks, and classification outputs into actionable, visual, and natural-language clinical reports for ophthalmologists and healthcare practitioners.

---

## File Structure & Component Manifest
All files for Module 5 are contained strictly inside `module5_explainability/`:

```
module5_explainability/
├── README.md                     # Module documentation & API reference
├── create_mock_screening_data.m  # Synthetic screening input data generator
├── generate_gradcam.m            # Grad-CAM & saliency overlay heatmap generator
├── generate_xai_maps.m           # Multi-modal XAI visualization engine
├── compute_lesion_importance.m   # Lesion contribution weighting calculator
├── generate_clinical_text.m      # Clinical text & recommendations synthesizer
├── build_summary_figure.m        # 2x3 multi-panel diagnostic graphics builder
├── export_html_report.m          # Responsive HTML clinical report exporter
├── generate_report.m             # Primary entry point function for Module 5
├── demo_module5.m                # Standalone demo executable script
└── tests/
    └── test_module5.m            # Automated unit test suite
```

## Data Interface Specification

### Primary Entry Point Signature
```matlab
report_data = generate_report(screening_data, output_dir)
```

### Input Contract (`screening_data` struct)
Module 5 receives a unified `screening_data` struct from the pipeline:

```matlab
screening_data = struct(...
    'patient_id', 'PAT-2026-9042', ...
    'patient_name', 'John Smith', ...
    'age', 62, ...
    'eye_side', 'OD', ...               % OD = Right Eye, OS = Left Eye
    'date', '2026-08-24', ...
    'raw_image', raw_img_matrix, ...
    'enhanced_image', enhanced_img, ...
    'iqa_result', struct('status', 'Good', 'quality_score', 0.92), ...
    'segmentation_results', struct(...
        'vessels_mask', vessel_mask, ...
        'optic_disc_mask', od_mask, ...
        'microaneurysms_mask', ma_mask, ...
        'hemorrhages_mask', hem_mask, ...
        'exudates_mask', ex_mask, ...
        'lesion_counts', struct('microaneurysms', 14, 'hemorrhages', 5, 'exudates', 8)...
    ), ...
    'dr_grading_result', struct(...
        'predicted_grade', 2, ...         % 0: Normal, 1: Mild, 2: Moderate, 3: Severe, 4: PDR
        'grade_label', 'Moderate NPDR', ...
        'confidence', 0.88, ...
        'class_probabilities', [0.02, 0.05, 0.88, 0.04, 0.01] ...
    ), ...
    'model', net_object ...               % (Optional) Trained CNN model
);
```

## How to Run

### Run Demo Script
In MATLAB, execute:
```matlab
run('module5_explainability/demo_module5.m')
```

### Run Unit Tests
In MATLAB, execute:
```matlab
runtests('module5_explainability/tests/test_module5.m')
```
