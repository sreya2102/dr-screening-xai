# Demo Samples Instructions

Place sample retinal fundus images in this directory to run local demonstrations with `run_module3_demo.m`.

## Expected Image Formats:
- JPEG (`.jpg`, `.jpeg`) or PNG (`.png`) or TIFF (`.tif`, `.tiff`)
- Standard retinal fundus view (e.g. 512x512, 1024x1024, or original resolution)

## Usage:
`run_module3_demo.m` in `module3_segmentation/` will automatically look for sample images in `demo_samples/` or generate a synthetic retinal fundus test image if no external image file is found.

*Note: Do not commit copyrighted dataset images directly into Git if redistribution is restricted.*
